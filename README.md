# Wedding-work

A high-performance, low-latency, and culturally authentic **Telugu Traditional Wedding Invitation (కళ్యాణ మహోత్సవం)** web application.

## 🌸 Key Cultural & Design Highlights

- **Temple Sanctum Entrance (దివ్యాలయ ప్రవేశం)**: 3D carved wooden temple doors, sacred Kalasham, and authentic flickering brass deepams.
- **Realistic Velvety Rose Petals Physics**: Custom organic 3D rose and fragrant jasmine petal shower with air resistance and tumbling flight.
- **Royal Kanchi Pattu Pelli Patrika (శుభలేఖ)**: Traditional zari borders, Lord Venkateswara and Ganesha blessings, and authentic Telugu panchangam muhurtham text.
- **7 Sacred Telugu Rituals Showcase (సప్తపది & ఆచారాలు)**: Interactive cultural guide covering Nalugu, Kashi Yatra, Jeelakarra Bellam, Mangalasutram, Talambralu, Saptapadi, and Arundhati Darsanam.
- **Traditional Banana Leaf Feast (సాంప్రదాయ కళ్యాణ విందు భోజనం)**: Interactive Andhra & Telangana wedding delicacies spread.
- **Zero-Latency Web Audio Synthesizer**: Procedural Tanpura drone + Kalyana Nadaswaram melody in Raga Kalyani + resonant temple bell chimes.
- **Bilingual Experience**: Instant toggle between Telugu (తెలుగు) and English without page reloads.
- **Interactive RSVP with Direct WhatsApp Sharing**: Instant confirmation, guest counter, and one-click WhatsApp message generation.
- **Calendar Synchronization**: One-click Google Calendar sync and `.ics` file download for Apple and Outlook calendars.
- **Live Muhurtham Countdown**: Real-time ticker for days, hours, minutes, and seconds.

## 🚀 Technology Stack

- Pure HTML5, Vanilla CSS3 (Custom Design System & Hardware-Accelerated Transforms), and Vanilla JavaScript.
- Zero heavyweight runtime dependencies for optimal speed and mobile performance.

## 💻 Running Locally

Open `Index.html` directly in any modern browser, or run a local HTTP server:

```bash
# Using Node.js
npx serve .
# Or Python
python -m http.server 3000
```
